# Extração de leitura de medidor de energia

Serviço de inferência (BentoML) que recebe a foto de uma leitura de medidor de energia
e devolve número do medidor, função, consumo e grau de confiança, para apoiar a
triagem que hoje é feita por conferência manual na distribuidora.
